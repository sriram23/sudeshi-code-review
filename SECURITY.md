# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue.

Report security concerns privately to the repository maintainer through the contact method listed on the maintainer's GitHub profile. Include steps to reproduce, impact, and any relevant evidence.

Do not include real API keys, passwords, tokens, or other sensitive credentials in reports.

## Scope

Sudeshi Code Review is an early-stage static analysis tool. It may miss vulnerabilities or report false positives and must not be treated as a guarantee of repository security.

When AI review is enabled, selected source context is sent to Sarvam AI. Do not submit source code you are not authorized to share.
